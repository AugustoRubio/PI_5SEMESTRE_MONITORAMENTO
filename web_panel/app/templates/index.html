Topologia e Recursos do Projeto

Este painel atua como o orquestrador central para a execução de testes, geração de tráfego e simulações. Os recursos disponíveis incluem:

  • Simulação Intranet: Scripts Python focados na geração assíncrona (via aiohttp) de tráfego HTTP para estressar APIs e bancos de dados, simulando comportamento real de alunos e professores na plataforma acadêmica.
  • Testes de Microserviços (SOA): Ambiente dedicado para estressar endpoints de faturamento (Billing) e processos intensivos (CPU/RAM), validando estratégias de Auto Scaling com Docker.
  • Segurança (SPI/DPI): Geração de tráfego malicioso contendo payloads de SQLi, XSS, Path Traversal e Força Bruta para acionar alertas no Suricata, Wazuh e pfSense.
  • Monitoramento (SNMP/Zabbix): Emulação de dispositivos SNMP (Nobreaks, Sensores) e integração de métricas via LLD no Zabbix para observabilidade unificada do ambiente.
Dica: Navegue pelos menus superiores Simulação Intranet e Simulações para iniciar testes, monitorar containers ou configurar o comportamento dos agentes.
