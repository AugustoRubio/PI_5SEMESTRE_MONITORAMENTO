Topologia do Projeto

Este painel atua como o orquestrador central para as simulações de rede e segurança. A infraestrutura é composta por:

  • Servidor Físico (Debian 12): Hospeda este painel web e o simulador de redes GNS3.
  • GNS3 (Rede Interna): Contém roteadores (Mikrotik, pfSense), switches e as máquinas virtuais que atuam como vítimas (Simulador SNMP) e atacantes internos.
  • VPS Externa: Atua como o servidor Zabbix para monitoramento e também como origem de ataques externos (DDoS via WAN).
  • Túneis (GRE/Wireguard/OSPF): Garantem a comunicação roteada entre a VPS externa e a rede interna do GNS3.
Dica: Utilize o menu Simulações acima para interagir com os dispositivos SNMP ou iniciar ataques de rede.
