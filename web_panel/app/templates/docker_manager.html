Gerenciamento de Containers (Simuladores)

Orquestre os serviços em background responsáveis por emular dispositivos, gerar tráfego malicioso e realizar testes de estresse SOA.

O stack do Docker Compose gerencia quatro agentes essenciais para o funcionamento das simulações avançadas no servidor:

  • snmpsim_pi: Simula o tráfego SNMP (Sensores e Nobreaks) para o Zabbix.
  • bruteforce_pi: Agente do Red Team para tentar quebrar credenciais via HTTP.
  • web_traffic_bot: Robô que gera tráfego simulando assinaturas DPI maliciosas (Suricata).
  • soa_stress_pi: Utilitário para geração massiva de testes em microserviços e APIs de faturamento.
Como funciona?

Ao clicar em Subir Stack, o sistema executa silenciosamente o comando docker compose up -d na pasta interna dos simuladores.

Isso ativa todos os contêineres e cria as redes isoladas necessárias para que o painel web possa despachar comandos para os agentes em background.

Atenção: Se o status estiver parado (Down), os ataques de força bruta, tráfego web e SOA Stress falharão, pois dependem destes contêineres de apoio rodando.
